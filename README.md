# xshi-math

Public monorepo **in planning** for Xiang Shi's personal math notes:
tutorials, Python visualization / numerical demos, and optional Lean.

Nothing has been migrated yet. The durable plan lives in this repo so the
later cutover ("一次性全合") can happen in one approved pass.

## Intended tracks

- **Incerto / fat tails** — migrate from private [`incerto-wiki`](https://github.com/xshi19/incerto-wiki) after a public-safety scrub. Current site: [xshi19.github.io/incerto-wiki](https://xshi19.github.io/incerto-wiki/).
- **Information Geometry** — new track, stub first.
- **Normix theory** — tutorial-style theory pages and demos only. The JAX package and API stay in [`normix`](https://github.com/xshi19/normix).

Shared MyST / Kami-like visual language. Personal hub:
[xshi19.github.io](https://xshi19.github.io/).
