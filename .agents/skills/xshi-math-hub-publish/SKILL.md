# xshi-math Hub Publish

Thin publish note for this monorepo. Normix's `$docs-publish` skill and
`gh-pages` workflow remain upstream; they own
`https://xshi19.github.io/normix/`.

## Canonical facts

- Four MyST projects: landing, Incerto, IG, Normix theory (`myst.*.yml`).
- Build: `npm ci` (once), then `npm run build` → `scripts/build_sites.py`
  assembles `_build/html/`.
- Check: `npm run check:html`.
- Public base: `https://xshi19.github.io/math/` (landing) with track prefixes
  `/math/incerto/`, `/math/ig/`, `/math/normix-theory/`, plus shared
  `/math/notation/`.
- Hub checkout (typical local path): `/workspace/xshi19.github.io`.
- Phase 4 is live: the hub serves `/math/` and a full old-site mirror under
  `/incerto-wiki/`, overlaid with 28 generated compatibility pages. The private
  `incerto-wiki` repository's own Pages was removed; owner freeze/archive is
  still outstanding. Math authoring for all three tracks belongs here.
- The compatibility tree is generated by `scripts/write_legacy_incerto.py`
  from `docs/plan/url-map.csv` at `_build/legacy/incerto-wiki/` during the build.
  It contains only mapped HTML, not the retained legacy site or its assets.
- Never touch `/normix/` or change Pages settings through this workflow.

## Local build

```bash
npm ci
npm run build
npm run check:html
```

Preview under the real path:

```bash
mkdir -p _build/preview/math
rsync -a --delete _build/html/ _build/preview/math/
python3 -m http.server 8000 --directory _build/preview
```

Open `http://localhost:8000/math/` and the three track bases. Review equations
and desktop/mobile navigation when changing content or theme.

## Optional hub transfer

After a clean local build and HTML check, from this repository:

```bash
rsync -a --delete /workspace/xshi-math/_build/html/ /workspace/xshi19.github.io/math/
```

Trailing slashes matter. Replace only `math/`; preserve the hub's entire
`incerto-wiki/` mirror and its compatibility pages. Never sync the generated
compatibility tree with `--delete` into the hub: that would erase retained pages,
downloads, and assets. When compatibility updates are in scope, overlay the
generator's output using the [cutover runbook](../../../docs/plan/phase-4-cutover-runbook.md)
and retain its rollback artifacts. Do not hand-author compatibility pages.

Review and commit/publish the hub change separately. Do not run the transfer
unless the user asked to refresh the live hub artifact.

## Completion Check

- Build and HTML check results are reported (or explicitly skipped).
- Hub transfer, if any, names source and destination paths.
- The legacy mirror, compatibility pages, and rollback artifacts are preserved;
  unresolved mappings are reported, not silently removed.
- `/normix/` was not modified.
- Live Pages verification is reported as not run unless actually performed.
