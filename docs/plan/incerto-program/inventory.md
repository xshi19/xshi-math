# Book and chapter inventory

This is a proposed concept map, not a transcription or a chapter summary. Topic labels are ours. Chapter numbers refer to the editions in [sources.md](sources.md); book bodies and paper theorem locators still need direct review. `state.yaml` owns the records. An asterisk after a concept ID means an existing Incerto body; it does not mean Lean verification.

The baseline has **7 books, 125 numbered chapters, 187 book source units including supplements, 14 papers, and 101 unique concepts**. Repeated concepts share one home. The expanded editions flagged below are not claimed complete.
