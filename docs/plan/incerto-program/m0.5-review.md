1. Scanned all flat Incerto Markdown and the hub for U+2019 and apostrophe/whitespace/`s` sequences. Only the glossary has a literal curly apostrophe (`Taleb’s`); most possessives use straight U+0027. There are no inserted spaces in either source form.
2. Inspected the pinned MyST 1.10.1 bundle. Its Markdown smartquotes option defaults on and enables the typographer replacement: ASCII possessive apostrophes become U+2019. The replacement itself inserts no space. No site-specific smartquote override or letter-spacing rule explained the possessive-only gap.
3. Inspected the retained hub artifact outside this checkout, `/workspace/xshi19.github.io/math/incerto/index.html`. It contains adjacent U+2019 U+0073 in `Karamata’s` and zero curly-apostrophe/whitespace/`s` matches. This is retained output of unknown deployed revision, not a successful fresh build or live review.
4. The source CSS formerly tried Charter/Georgia, then CJK serif families, before Palatino or generic serif. The local fallback resolves to Noto Serif CJK SC. FontTools inspection of the actual installed font reports U+2019 advance **1.000 em**, straight apostrophe **0.196 em**, and `s` **0.473 em**. Noto Serif gives U+2019 **0.250 em**; Liberation Serif gives **0.333 em**. The wide CJK punctuation glyph explains the apparent trailing blank without a whitespace character.
5. Updated `--incerto-serif` in `assets/styles/math.css` to try Latin serifs (including Palatino, Noto Serif, Liberation Serif, DejaVu Serif and Times) before the CJK families. CJK characters still fall back to the CJK fonts. Smartquotes remain enabled and no output post-processing was added.
