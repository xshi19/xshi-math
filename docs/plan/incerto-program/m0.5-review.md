## Review contract

Astra max reviews every mathematical claim in the 24 existing
`content/incerto-*.md` concept bodies. The hub and three concept indexes are
excluded from this denominator. Inventory definitions, propositions, equations,
derivations, examples, asymptotic assertions and numerical claims individually.
For each, check hypotheses, quantifiers, notation, boundary cases, logical steps,
source locators and whether the page supplies a proof, a sketch, a citation or
numerical evidence. Record a result even when no issue is found. Unchecked
claims remain explicit and prevent a page from being marked reviewed.

Math Site Editor reads each corresponding live page as a reader. Check the
explanation and prerequisite order, equation rendering, symbols, figure labels,
examples, proof/citation distinctions, links and desktop/mobile navigation.
Record deployment revision, review date, URL/fragment and viewport. A local
HTML build is separate evidence; an inaccessible live page remains unreviewed.

Produce one consolidated issues list for Xiang. Each issue carries a proposed
action; no concept page or site fix is authorized by this planning revision.
M0.5 closes when both reviews cover all 24 pages and the issues list for Xiang
records dispositions, assignments and any decisions still needed. Findings
affecting the two M1 claims must be resolved before the pilot starts; other
findings can remain explicitly assigned work.

## Standing live review rule

After **every site update**, Math Site Editor reviews the corresponding live
pages as a reader. Record the deployment revision/date, URLs, reader findings
and issue dispositions in `docs/records/incerto-site-review-YYYY-MM-DD.md`
(future path; append a separate entry for each update on the same day).
Include desktop/mobile reading, equations, figures, links and navigation.
The update remains pending reader review until this evidence is recorded.
M0.5 uses this file for its initial 24-page review; later records link back to
any issue they resolve. Neither an HTML check nor a mathematical review alone
satisfies the live reader gate.
